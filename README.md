# Jery AI Assistant 🤖

Jery is a personal Windows AI assistant built with Python.

## Features

- GUI interface
- Command processing
- Application launcher
- Persian and English commands

## Tech Stack

- Python
- PyQt6
- PyWin32

## Current Version

v0.1.0

## Roadmap

- Voice recognition
- Telegram integration
- Online AI mode
- Offline AI mode
